# nutrifit 애드센스 재심사 정비안 (2026-10-12)

거절 사유: "가치가 별로 없는 콘텐츠". 이 문서는 **분류안**이며 아직 아무것도 삭제·이동하지 않았다.

## 진단 요약

- 발행 216편 중 186편이 2026-09-12~13 이틀에 발행됨(대량 생성 패턴)
- 본문 중앙값 약 2,300자(공백 제외), 2,000자 미만 11편
- 같은 틀의 대상만 바꾼 변주(연령·성별 종합비타민, 부모님 선물 10편, 브랜드별 오메가3·유산균 등)
- 전 편 작성자 "NutriFit 영양정보팀", 전 편 제품 추천 블록(productPicks)

## 분류 결과

- 유지·보강 **76편** / 병합(301) **140편** (총 216편)
- 병합은 글을 버리는 것이 아니라, 겹치는 글의 알맹이를 허브 글 하나로 모으고 옛 주소는 301으로 허브에 연결하는 것
- 허브는 3,500자 이상, 직접 만든 표·계산 등 독자 요소, 실제 작성자·감수 표기를 목표로 한다
